Mega Rehaul Update!

Azami has now been completely rehauled were all her inner workings have changed! Also the addition of new cogs and updated cogs.
And most error checks were removed because most can be solved in on_command_error

- core/bot.py (The main file for the bot. That makes the bot class orientated as it is an autoshardedbot. Aswell as new way to load cogs and a personal server welcome message made for the Azami server!)

- cogs/basic.py: [invite, supportserver] (Now a way to invite people to your guild and invite people to your supportserver)
- cogs/economy.py: [daily, balance] (Get money! Rings are used as a placeholder for the money)
- cogs/emoji.py: [emoji, emojilist] (Enlarge emojis and get back the list of emojis)
- cogs/fun.py: [custom embeds] (Make your own embeds!)
- cogs/server.py: [botinfo] (Returns info about the bot)
- cogs/waifu.pu: [waifu] (Search for waifus!)

- core/setup.py (create the bot function and checks if Heroku is enabled to use it's token or it will use local token)
- core/utils.py (Utils for the bot making things easier in the long run, like for example a custom message maker that checks if the bot has perms to send messages or use embeds)
- core/webdriver.py (The webdriver from Heroku)
- etc (A bunch of extra files to make cogs run smoother)
- Small note: Database changed in this update from MySQL to PostgresSQL due to Heroku has better support with PostgresSQL also a music cog was made for the bot but will not be implemented publically yet due to lavalink issues.
